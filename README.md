# 🎮 PIXEL METEOR: F1 SURVIVAL ONLINE

## คู่มือ Demo เกม Multiplayer 4 คน (คอมพิวเตอร์ 4 เครื่อง)

เกมแข่งรถ F1 แนวเอาชีวิตรอด หลบอุกกาบาตบนสนามเดียวกันผ่าน **Java TCP Client–Server** ทุกเครื่องเห็นสถานะรถและอุกกาบาตจาก Server เดียวกัน

### 1. รูปแบบการเชื่อมต่อ

```text
          เครื่องที่ 1 (SERVER + PLAYER 1)
                 IP: <SERVER_IP>
                  TCP Port 6000
                         |
             เครือข่าย LAN / Wi-Fi
                /        |        \
       เครื่อง 2     เครื่อง 3     เครื่อง 4
       PLAYER 2     PLAYER 3     PLAYER 4
```

- **เครื่องที่ 1** เปิดทั้ง Server และ Client จึงเล่นได้ด้วย
- **เครื่องที่ 2–4** เปิด Client อย่างเดียว
- ไม่ต้องมีคอมพิวเตอร์เครื่องที่ 5

### 2. เตรียมก่อนเล่น

1. ติดตั้ง **Java JDK** บนคอมพิวเตอร์ทุกเครื่อง ตรวจด้วย `java -version` และ `javac -version`
2. คัดลอกโปรเจกต์ `OOP` เวอร์ชันเดียวกันลงทุกเครื่อง รวม **โฟลเดอร์ `assets/` ที่มีรูป PNG**
3. ให้ทั้ง 4 เครื่องเชื่อมต่อเครือข่ายที่ติดต่อกันได้ (ชื่อ Wi-Fi เดียวกันอย่างเดียวอาจไม่พอ หากคณะแยกอุปกรณ์จากกัน)
4. เปิด **Command Prompt / Terminal ในโฟลเดอร์ `OOP`** ก่อนใช้คำสั่งต่อไปนี้

### 3. Compile โปรแกรม (ทุกเครื่อง)

หากยังไม่มีไฟล์ `out/` หรือเพิ่งเปลี่ยนโค้ด ให้รันคำสั่งนี้ในโฟลเดอร์ `OOP`:

```cmd
javac -encoding UTF-8 -d out src/Main.java model/CarView.java model/MeteorView.java model/ViewState.java network/GameClient.java network/GameServer.java ui/GB.java ui/RetroPanel.java ui/GameAssets.java ui/PreviewScreens.java ui/GamePanel.java
```

> คำสั่งนี้สำหรับ **เวอร์ชัน Modern UI** ที่มี `ui/GameAssets.java` และ `ui/PreviewScreens.java` หากไฟล์ดังกล่าวไม่มีอยู่ ให้ใช้รายชื่อ `.java` ตามโปรเจกต์ที่มีจริง

### 4. เครื่องที่ 1 — เปิด Server และเข้าเล่น

**(ก) หา IP ของเครื่องที่ 1:**

```cmd
ipconfig
```

ดู `IPv4 Address` ของ Wi-Fi / Ethernet ที่ใช้งาน เช่น `192.168.1.10` (**ตัวเลขนี้เป็นตัวอย่างเท่านั้น**)

**(ข) เปิด Server:**

```cmd
java -cp out network.GameServer 6000
```

ควรเห็น `PIXEL METEOR SERVER listening on port 6000` — **เปิด Terminal นี้ค้างไว้**

**(ค) เปิด Client ของ Player 1:** เปิด Terminal อีกหน้าต่าง แล้วรัน

```cmd
java -cp out Main 127.0.0.1 6000
```

### 5. เครื่องที่ 2, 3 และ 4 — เข้าเล่น

แต่ละเครื่องเปิด Terminal ในโฟลเดอร์ `OOP` แล้วรันคำสั่ง **เหมือนกันทุกเครื่อง**:

```cmd
java -cp out Main 192.168.1.10 6000
```

**เปลี่ยน `192.168.1.10` เป็น IPv4 จริงของเครื่องที่ 1** ทั้งสามเครื่องต้องใช้ IP Server และ Port `6000` ตรงกัน

### 6. เริ่มเกมและปุ่มควบคุม

1. รอจนหน้า Lobby แสดง `CONNECTED 4/4`
2. ให้ทุกคนคลิกหน้าต่างเกมของตัวเองแล้วกด **Enter** เพื่อ Ready
3. เมื่อครบ `READY 4/4` เกมจะเริ่มเอง
4. ทุกคนควบคุมเฉพาะรถตัวเอง แต่เห็นรถและอุกกาบาตชุดเดียวกัน

| ปุ่ม | การทำงาน |
|---|---|
| `Enter` | พร้อมเริ่มเกมใน Lobby |
| `←` | เปลี่ยนเลนซ้าย |
| `→` | เปลี่ยนเลนขวา |
| `R` | พร้อมเล่นรอบใหม่ หลัง Game Over |

**กติกา:** หลบอุกกาบาต อย่าให้รถชน ผู้เล่นที่เหลือรอดคนสุดท้ายเป็นผู้ชนะ

### 7. ทดสอบเครือข่ายก่อน Demo (แนะนำ)

หลังเปิด Server แล้ว ให้เครื่องที่ 2–4 เปิด **PowerShell** และรัน:

```powershell
Test-NetConnection 192.168.1.10 -Port 6000
```

เปลี่ยน IP ตามจริง ผลที่ต้องการคือ `TcpTestSucceeded : True`

หากเชื่อมต่อไม่ได้ ให้ตรวจ IP, Port, การอนุญาต **TCP ขาเข้า Port 6000** ใน Windows Firewall ของเครื่อง Server และข้อจำกัด Wi-Fi คณะ (เช่น Client Isolation) **ไม่แนะนำให้ปิด Firewall ทั้งระบบ** หากเครือข่ายคณะแยกอุปกรณ์ ให้เตรียมเครือข่ายสำรองที่อนุญาตให้เครื่องเชื่อมต่อกันได้ตามกฎของคณะ

### 8. ปัญหาที่พบบ่อย

| อาการ | วิธีตรวจสอบ |
|---|---|
| `Address already in use` | Port 6000 ถูกใช้อยู่: ตรวจด้วย `netstat -ano \| findstr :6000` แล้วหยุด Server เก่าหรือใช้ Port ใหม่ร่วมกันทุกเครื่อง |
| Client ขึ้น `DISCONNECTED` | เช็กว่า Server เปิดอยู่, IP/Port ถูกต้อง, TCP เชื่อมต่อผ่าน และ Firewall อนุญาต |
| `CONNECTED` ไม่ครบ 4/4 | ตรวจว่า Client ทั้งสี่เชื่อม Server ตัวเดียวกัน และไม่มีเครื่องถูกเครือข่ายคณะบล็อก |
| เกมไม่เริ่ม | ต้องเชื่อมต่อ **4 คน** และกด **Enter ครบทุกคน** |
| กดลูกศรไม่ขยับ | คลิกหน้าต่างเกมก่อน และตรวจว่ารถยังไม่ตกรอบ |
| รูป PNG ไม่ขึ้น | ตรวจว่าเปิด Terminal จากโฟลเดอร์ `OOP` และมี `assets/` ครบ |

### 9. หลังเล่นเสร็จ

ปิด Client ทุกเครื่อง จากนั้นกลับไปที่ Terminal ของ Server (เครื่องที่ 1) แล้วกด **Ctrl + C** ไม่ต้องเปิด Server ทิ้งไว้
